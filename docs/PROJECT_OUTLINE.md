# De Cuong Du An Web HR

## Muc tieu

Xay dung he thong quan ly nhan su co kha nang dang nhap, phan quyen, quan ly ho so nhan vien, phong ban va cac du lieu nen tang cho cac module HR tiep theo.

## Pham vi giai doan dau

- Xac thuc nguoi dung bang email va mat khau.
- Phan quyen theo vai tro: Admin, HR Manager, HR Staff.
- Quan ly danh sach nhan vien.
- Them, sua, xoa, tim kiem va loc ho so nhan vien.
- Quan ly danh muc phong ban.
- Luu tru du lieu bang PostgreSQL.
- Thiet lap CI voi GitHub Actions.

## Ngoai pham vi tam thoi

- Cham cong.
- Tinh luong chi tiet.
- Phe duyet nghi phep.
- Ky hop dong dien tu.
- Tich hop email, lich, SSO.

## Ben lien quan

- Quan tri he thong.
- Nhan su.
- Quan ly phong ban.
- Nhan vien.
- Dev/DevOps.

## Tieu chi thanh cong

- Chay duoc frontend va backend o moi truong local.
- Dang nhap bang tai khoan admin seed san.
- Tao va cap nhat ho so nhan vien tren giao dien.
- API co validation va bao loi ro rang.
- CI chay lint va build thanh cong.
